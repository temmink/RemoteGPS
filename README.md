# RemoteGPS

This repository is used for **bug reports** and **feature requests** only. No source code is hosted here.

RemoteGPS turns your iPhone into a Bluetooth GPS remote for DJI Osmo Action 4, Osmo Action 5 Pro and Osmo Action 6 cameras.

Use the [Issues](https://github.com/temmink/RemoteGPS/issues) tab to:

- 🐛 Report a bug
- 💡 Request a new feature
- ❓ Ask a support question

Support page: https://temmink.github.io/RemoteGPS/
Privacy policy: https://temmink.github.io/RemoteGPS/privacy-policy.html
